This page is mandatory and must be completed

A valid Plex server URL and token are required. Choose either option:

  • Sign in with Plex: Approve access in the Plex window, including two-factor authentication if enabled. Leave Plex URL blank to find servers owned by your account. One server connects automatically; with multiple servers, select one. An existing URL is kept. Quickstart fills the token and validates the connection automatically. If the popup is blocked, use Open Plex.
  • Manual entry: Enter your direct server URL and an existing X-Plex-Token, then select Validate. If automatic discovery cannot find or connect to your server, your approved token is kept; enter the URL and validate manually.

Quickstart and Kometa must both be able to reach the server address, including when running in Docker. https://app.plex.tv is not a direct server address.

A plex.direct address is normal for Plex HTTPS connections, not an authentication token. Discovery does not enable remote access or change your server settings. Keep your Plex token private.
