A valid Plex server URL and token are required. Choose either option:

  • Sign in with Plex: Approve access in the Plex window, including two-factor authentication if enabled. Quickstart fills only the token; enter the server URL yourself. An existing URL is kept and validated after sign-in. If the popup is blocked, use Open Plex.
  • Manual entry: Enter your direct server URL and an existing X-Plex-Token, then select Validate. You can also obtain the token through sign-in before entering the URL.

Quickstart and Kometa must both be able to reach the server address. If Plex runs in Docker and Kometa runs on another machine, use the Docker host's LAN address and published Plex port, not a private container IP or localhost. https://app.plex.tv is not a direct server address.

A plex.direct address is normal for Plex HTTPS connections, not an authentication token. Sign-in does not change your server address or remote-access settings. Keep your Plex token private.
