This page is optional and currently requires Kometa nightly
Tracearr allows Kometa to create collections from Plex watch history. Enter the Tracearr URL and a Public API key, then press "Validate". Quickstart will load the Plex servers available to that key.
The API key can be created in Tracearr under Settings > Public API and must begin with trr_pub_.
